Getting Started

  1. Download the recommended APK from the official Releases page.
  2. Grant installation permission when prompted by Android or your file manager.
  3. Add a trusted extension repository and install the sources you wish to use.
  4. Add titles to your library and open any chapter to begin reading and translating.

Official updates can be installed directly over existing versions without losing your library, history, or configurations.

Translation Setup

Yomotsu translates text directly inside speech bubbles using Computer Vision (OCR) and Artificial Intelligence models. You can adjust the source and target languages at any time.

  1. Open More → Settings → Translation.
  2. Select the original chapter language and your desired target language.
  3. Choose your engine: ML Kit (offline), Google Translate, DeepL, Google Gemini, or OpenRouter.
  4. Optionally enable automatic background translation upon download completion.
  5. Keep sound effects (SFX) translation disabled if you prefer preserving original onomatopoeias.

Series Glossary

In the details menu of any series, open Translation Glossary to define custom translations for recurring names, titles, or skill terms.

Edit or Re-translate Individual Bubbles

While reading a translated chapter, long-press any speech bubble. You can manually edit the text or tap Re-translate to run that single bubble through a different engine without reprocessing the entire page.

Smart Typesetting

Text lines belonging to the same bubble are automatically grouped. Yomotsu dynamically calculates font sizing, hyphenation, contrast, and alignment based on background artwork.

No Text Detected?

Ensure the selected source OCR language matches the chapter. Extremely low-resolution, blurred, or heavily stylized decorative fonts may reduce OCR accuracy.

API Keys

  • ML Kit: Runs 100% locally on your device without requiring an API key or internet access.
  • Google Translate: Built-in web client; no API key needed.
  • DeepL: Provide your personal Free or Pro API key in the designated field.
  • Google Gemini & OpenRouter: Enter your API key and configure model choices in advanced settings.

All keys remain encrypted and stored locally in your private app preferences. Never share screenshots showing your credentials.

Downloads & Storage

Choose a dedicated storage directory with permanent read/write access. If chapters fail to appear after modifying directories, reselect your location under Settings → Data & Storage.

Yomotsu stores manga chapters in standard CBZ archives. Translations are stored in non-destructive companion layers, keeping original image files pristine.

Cloudflare & WebView

When an extension encounters Cloudflare or bot protection, tap the WebView button inside the source, solve the challenge, and refresh. Ensure your Android System WebView is kept up to date via Google Play.

Trackers

Sync your reading and watching progress across external tracking services (AniList, MyAnimeList, Kitsu, Shikimori, etc.). Log in via Settings → Tracking and bind titles as desired.

Smart TV Streaming (Google Cast / Chromecast)

Yomotsu includes native Chromecast integration for streaming anime episodes directly to Smart TVs, Android TV, Google TV, or Chromecast dongles connected to your local network.

  1. Ensure your Android device and TV are connected to the same Wi-Fi network.
  2. Open any anime episode (online stream or local download) and launch playback.
  3. Tap the official Google Cast icon located in the upper-right corner of the MPV player.
  4. Select your TV or cast receiver from the discovered devices dialog.
  5. Playback will launch on your TV, and your smartphone will switch into a responsive remote control with play/pause, scrub slider, 10s skip, and episode switching.

No TV app installation required: Yomotsu uses the native Google Cast receiver protocol and an embedded local proxy server with HTTP header rewriting to bypass CDN hotlink protections seamlessly.

Source Migration

If an extension source becomes inactive, use the Migration tool under Browse → Migrate. Select the previous source, choose your replacement, and verify title matches before proceeding.

Library Updates

Large library refreshes can trigger rate limits on third-party servers. Organize titles into custom categories and adjust global update schedules to balance convenience and server load.
